Install

  1. Download AudioPaper.dmg from the latest release. It is signed with a Developer ID and notarized by Apple, so it opens without warnings.
  2. Open it and drag AudioPaper into Applications. It must be in Applications for its widgets to show up.
  3. Open AudioPaper from Applications. A small display-and-note icon appears in the menu bar; there’s no window to start with.

You need macOS 26 or later and the Music app. If you’d rather build it yourself, the README has the steps.

The first launch

If music is already playing, macOS asks: “AudioPaper” wants access to control “Music”, with AudioPaper’s reason: AudioPaper asks Music what is playing when it starts, so your wallpaper matches right away.

  • Allow, and the wallpaper changes straight away.
  • Don’t Allow, and it changes when the next song starts instead. Track changes don’t need this permission. You can change your answer in System Settings → Privacy & Security → Automation.

AudioPaper uses this only to read the current track (and, as a last resort, the cover art Music already has). It never plays, pauses or skips anything.

Your own wallpaper is remembered the first time AudioPaper changes it, so Restore Original Wallpaper can put it back later.

Getting more art

Out of the box, AudioPaper finds covers for nearly everything, and fan art and photos from TheAudioDB and Wikimedia Commons. Well-known artists usually have plenty; newer or smaller artists may have one image or none. These optional keys find more. Add them in Settings → Accounts; they’re saved in your Keychain as you type.

ServiceWhat it addsHow to get a key
fanart.tvFan-made artist backgrounds at 1920 × 1080 and 4K. Often the best source for well-known artists.Make a free account at fanart.tv, then create an API key from your profile. Paste it into Project API key. A Personal API key is optional; with one, new images reach you sooner.
Brave SearchImages from the wider web, used only when the other sources find fewer than three usable images for a song.Sign up at the Brave Search API dashboard. The free plan allowed 2,000 searches a month as of September 2026; AudioPaper uses at most three per song, and only for songs that need it.
DeviantArtFan art, with links to each artist’s DeviantArt profile. This source hasn’t yet been tested against a live DeviantArt account.Register an application and paste its Client ID and Client secret.
TheAudioDBWorks without a key. A personal key only matters if you’re a supporter of theirs.About TheAudioDB’s API

Each song is searched once, when it first plays. Art found for an artist is kept in a pool of up to 24 images, so their other songs have something to show straight away.

The menu bar menu

Click the icon in the menu bar. From the top:

  • The song, and the artist and album.
  • The credit for the image on screen. Choose it to open the artist’s profile, when there is one. View Image on … (or View Album on …) opens the page the image came from.
  • Next Image, Pause Wallpaper Changes and Restore Original Wallpaper.
  • Show Mini Player, Settings… and Quit AudioPaper.

The icon shows a pause mark while wallpaper changes are paused.

The Mini Player

A small window, like Music’s MiniPlayer: the image on screen, its credit, a strip of every image in rotation, and buttons for Next Image, Pause and Restore Original Wallpaper. Click an image in the strip to show it now.

  • Open it from the menu (⌥⌘M), by clicking a widget, or by clicking AudioPaper’s Dock icon.
  • Move it by dragging anywhere on its background.
  • The … button has Float on Top and Show on All Desktops. The same options are in the Window menu.
  • It remembers where you left it, and whether it was open when you quit.

Widgets

Right-click the desktop, choose Edit Widgets, and search for AudioPaper.

  • Now Playing (small, medium, large): the track, the image on screen and its credit. The medium and large sizes have working Pause and Next Image buttons.
  • Artwork (all sizes): just the image on screen, with its credit.

Clicking a widget opens the Mini Player. Like all macOS widgets, they turn grey while another app’s window is in front and the widget style is set to Automatic; clicking the desktop brings the colour back. You can change this in System Settings → Desktop & Dock → Widget style.

The Dock icon

AudioPaper stays out of the Dock unless it needs to be there: while the Mini Player is open, or when you’ve turned off Show in menu bar, so there is always a way back in. Clicking the Dock icon opens the Mini Player; right-clicking it offers Next Image, Pause and Restore Original Wallpaper.

If you hid the menu bar icon and closed the Mini Player, open AudioPaper from Applications again to bring the Mini Player back.

Pausing, slowing down, restoring

  • Pause Wallpaper Changes keeps the current image until you resume, whatever you play.
  • Settings → General → Change fan art every sets the rotation, from 15 seconds to 5 minutes.
  • Settings → General → Wallpaper → Album cover shows only the cover: no fan art, and no fan-art lookups.
  • Restore my wallpaper when music stops puts your own wallpaper back 30 seconds after playback stops.
  • Restore Original Wallpaper puts it back now.

The wallpaper AudioPaper sets is a real wallpaper, so it stays if you quit, and shows on every desktop and display.

Storage

Downloaded art is kept so that replays cost nothing. Settings → General → Storage shows how much is in use, sets the limit (250 MB to 2 GB, 500 MB by default), and has Clear Cache…, which deletes it all except the images on screen. When the limit is reached, the images used least recently go first.

When something doesn’t work

The wallpaper doesn’t change

  • AudioPaper follows the Music app only. Other players aren’t supported yet.
  • Check the menu bar icon: if it shows a pause mark, choose Resume Wallpaper Changes.
  • The first song after launch needs the Automation permission (see The first launch). The next song works without it.

Only the album cover, no fan art

  • Check Settings → General → Wallpaper is set to show fan art, and that sources are switched on in Settings → Sources.
  • Some artists have no art in the sources you have. Adding a fanart.tv or Brave Search key finds more.
  • When nothing is found for a song, AudioPaper waits a week before searching for it again, so it doesn’t ask the services over and over.

The art shows the wrong artist

AudioPaper identifies artists through MusicBrainz, using the song as well as the name, so two artists with the same name aren’t mixed up. It can still get it wrong, especially for new releases MusicBrainz doesn’t know yet. Use View Image on … to see where the image came from, and please open an issue with the artist and song.

An image has text on it, or isn’t art

The filters catch most text, screenshots and product photos, but stylised band logos can get past them. Next Image moves on; an issue with the image’s page helps improve the filters.

The widgets aren’t in the widget gallery

AudioPaper must be in your Applications folder, and must have been opened once from there.

The widgets look grey

That’s macOS dimming widgets while another window is in front; see Widgets.

Removing AudioPaper

  1. Choose Restore Original Wallpaper, so your own wallpaper is back.
  2. If you added keys, clear them in Settings → Accounts, which removes them from your Keychain.
  3. If you turned on Open at login, turn it off in Settings → General.
  4. Quit AudioPaper and drag it from Applications to the Trash.
  5. To remove its downloaded art and settings too, delete these two folders:
    • ~/Library/Containers/com.audiopaper
    • ~/Library/Group Containers/7JQGQ7CRH8.com.audiopaper
